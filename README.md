
# Exploratores OSINT Toolkit

**Exploratores** is a responsive, modular OSINT toolkit designed to support online investigative research. It is organized into thematic sections (search engines, email analysis, social networks, business, communities, and more). This project modernizes an existing OSINT suite by removing outdated table-based layouts and introducing semantic HTML5 structures, CSS3 Flexbox layouts, and JavaScript components as needed.

### ✨ Key Features

- ✅ Fully responsive and accessible interface optimized for all devices.
- ✅ Unified and consistent navigation across all toolkit sections.
- ✅ Semantic HTML5 layout using elements such as `<aside>`, `<main>`, and `<section>` for clear structure.
- ✅ Advanced search options for:
  - Business & Government (companies, public tenders, official registers)
  - Clear Web and Tor Network
  - Social networks and communities (Reddit, Discord, TikTok, Telegram, etc.)
  - Email analysis (lookup, leaks, reputation, related OSINT)
- ✅ Modular design: each page is independent and easily expandable.

### 📚 Documentation and References

This toolkit follows OSINT best practices inspired by:

- *Open Source Intelligence Techniques – 11th edition* by Michael Bazzell

The project emphasizes core OSINT professional principles, including investigative virtualization, operational security (OPSEC), customization of investigative virtual machines, and effective use of open-source research tools.

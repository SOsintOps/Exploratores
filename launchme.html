Exploratores OSINT Toolkit

How to Start

Exploratores is an OSINT toolkit developed to support investigations.

To start your investigation, please select one of the tool pages available from the navigation bar above.

To understand how to use, contribute to, or find answers about Exploratores, please refer to these key resources:

  • Project Guidelines: Learn about the coding standards, page structure, and style conventions.
  • Customise Pages: Discover how to add new tools, modify layouts, and tailor the toolkit to your needs.
  • Frequently Asked Questions (FAQ): Find answers to common questions about the toolkit's purpose, usage, development, and OSINT resources.

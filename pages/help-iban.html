What the IBAN Tool does

The IBAN Tool validates International Bank Account Numbers offline, extracts bank details from a local database, and opens targeted search queries in external search engines. Validation is performed entirely inside your browser — no data is sent to any server.

IBAN CHECKER

How to use the IBAN Checker

  1. Type or paste the IBAN into the input field. You can include spaces or write it without, for example: IT60 X054 2811 1010 0000 1234 56 or IT60X054281110100000123456. The tool normalises the input automatically.
  2. Validation runs as you type. A green message confirms the structure and checksum are valid. A red message means the format or checksum is wrong — check you copied the full number without missing or extra characters.
  3. When the IBAN is valid, two panels appear below the input field:
    • IBAN Information: country, check digits, total length.
    • Bank Information: bank name (if found in the local database), and the BBAN breakdown — routing codes, branch codes, and account number in the format specific to that country.

If the bank name shows as Not found in local database, the IBAN is still valid. The tool simply does not have that institution in its records.

ONLINE SEARCH BUTTONS

Online search buttons

When a valid IBAN is entered, the search buttons activate. Each button opens a new browser tab and runs a search for the IBAN on the selected engine or tool. The buttons are disabled until the IBAN passes local validation.

  • Google Search: general web search for the IBAN string.
  • Bing Search: same query on Bing.
  • Yandex Search: same query on Yandex.
  • Baidu Search: same query on Baidu.
  • IBAN Calculator: opens an external website for further validation.

BANK DATABASE COVERAGE

Bank database coverage

The local database identifies the bank name from the routing codes inside the BBAN. It currently covers 19 countries. Coverage levels:

  • Complete — all major banks are present.
  • Good — most banks are covered; uncommon institutions may be absent.
  • Partial — common banks are listed; many institutions are missing.
  • Minimal — only a handful of entries are included.

Full datasets for Germany (DE), Austria (AT), and Switzerland (CH) are available free from the respective national central banks as CSV or XLS files. To expand coverage, download the official file and convert the routing code to bank name mappings into the format used by the existing files in assets/js/bankDatabases/.

Catalogue Updates

Refresh the search catalogue from GitHub

For offline copies of the toolkit. Once a day the browser fetches the catalogue metadata from the project repository and, when a newer catalogue is published, downloads it, verifies its SHA-256 checksum and keeps it in this browser. Tools on hosts confirmed dead are then greyed out here too. The downloaded catalogue is applied from the next page you open. Off by default: when enabled, GitHub sees the requests (no cookies, no referrer). The site published on GitHub Pages is always current and does not need this.
